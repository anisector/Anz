# Anizium CloudStream test repo

Bu depo Anizium provider'ın güncel API geçiş sürümünü test etmek içindir.

## CloudStream repo URL

`https://raw.githubusercontent.com/anisector/anz/main/repo.json`

İlk build için GitHub Actions içinden **Build Anizium CloudStream plugin** workflow'unu çalıştırın. Başarılı build sonrasında `builds/plugins.json` ve `builds/Anizium.cs3` otomatik oluşturulur.
